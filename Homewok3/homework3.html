3. Statistical Cryptanalysis of Caesar Cipher

Automated key recovery using Chi-Squared (χ²) goodness-of-fit against standard English letter frequencies.

Comparison of Attack Approaches

  • Exhaustive Key Search (Brute-Force): Tries all 26 possible shift keys. Highly effective for humans inspecting outputs, but requires manual check unless paired with dictionary lookup.
  • Single-Letter Frequency Analysis (χ² Test): Compares unigram frequencies against expected language distributions. Fast $O(26 \cdot N)$, but struggles on very short ciphertexts (< 30 characters).
  • N-Gram Scoring (Bigrams / Trigrams): Evaluates log-probabilities of character sequences (e.g., "TH", "HE", "ING"). Extremely robust even for short ciphertexts because it captures local language structure.

4. Attack on Restricted Key Space Toy ECC vs. Caesar

Since private key $k \in [1..16]$, an attacker recovers $k$ from public key $Q = (8, 3)$ or ciphertext point $C_1 = (rG)$ using brute-force discrete log search.

Comparative Analysis

Feature Caesar Cipher Toy ECC Scheme
Key Space Size $26$ possible keys. $16$ valid non-zero points (mod 17 order).
Vulnerability Source Statistical redundancy: Letter frequencies in natural language remain unchanged under monoalphabetic substitution. Restricted key space: The private key space is small enough ($\vert{}G\vert{}=18$) to allow exhaustive scalar multiplication.
Real-World Feasibility Broken instantly by computer or hand regardless of key length. Infeasible on real secp256k1 ($2^{256}$ keys). Solving ECDLP takes $\approx 2^{128}$ operations (Pollard's rho).

Design Weaknesses: Toy vs. Full ECC

In this toy demo, the weakness comes entirely from the artificial restriction of the key space (mod 17 field). Additionally, directly mapping character ASCII codes to curve points without padding/randomization allows identical characters to yield identical ciphertexts if the same ephemeral key $r$ is reused (deterministic leakage).
