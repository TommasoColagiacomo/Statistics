Homework 4: Stochastic Modeling of Security Penetration

Simulating Bernoulli & Rademacher Random Walks, LLN Convergence, and CLT Behavior

1. Simulation Configuration

Model a penetration process over n systems (or time steps) across m independent attackers (trajectories). Each step produces an i.i.d. increment Xi:

  • Bernoulli Model: Xi ∈ {0, 1} with P(Xi = 1) = p.
  • Rademacher Model: Xi ∈ {-1, +1} with P(Xi = +1) = P(Xi = -1) = 0.5.


2. Theoretical Framework & Mathematical Normalizations

For a sequence of independent and identically distributed random variables X₁, X₂, ..., Xₙ with mean E[Xᵢ] = μ and variance Var(Xᵢ) = σ², we analyze three different scalings of the cumulative process:

1. Total Score: Sₙ = ∑ Xᵢ

Properties: E[Sₙ] = n · μ  |  Var(Sₙ) = n · σ²
As n → ∞, the variance grows linearly with n. The dispersion of total penetration scores among attackers widens without bound, making raw total scores unsuitable for direct comparisons across large systems.

2. Average Score: Sₙ / n = (1/n) ∑ Xᵢ

Properties: E[Sₙ/n] = μ  |  Var(Sₙ/n) = σ² / n
As n → ∞, the variance shrinks to 0. By the Weak Law of Large Numbers (LLN), the sample average converges in probability to the expected value:
P(|Sₙ/n - μ| > ε) → 0   as   n → ∞

3. Normalized Total Score: Sₙ / √n = (1/√n) ∑ Xᵢ

Properties: E[Sₙ/√n] = √n · μ  |  Var(Sₙ/√n) = σ²
By scaling by √n, the variance remains constant (equal to σ²) regardless of how large n grows. In the zero-mean Rademacher case (μ = 0, σ² = 1), the Central Limit Theorem (CLT) guarantees that Sₙ/√n converges in distribution to a Standard Normal distribution:
Sₙ / √n ➔ N(0, 1)   as   n → ∞

4. Cybersecurity Interpretation

Translating these mathematical limit theorems into the security domain provides key insights into system resilience and attacker dynamics:

  • System Size (n): As the number of systems or security layers increases, the cumulative variance grows. However, the average vulnerability per system (Sₙ/n) stabilizes around its true mean μ due to the Law of Large Numbers. In a zero-mean symmetric scenario (Rademacher), defense and attack capabilities balance out on average.
  • Number of Attackers (m): Increasing m allows us to observe the full probability distribution across independent attack campaigns. While individual trajectories deviate randomly, the collective ensemble of m attackers accurately reflects the theoretical Gaussian limit (CLT) predicted by the Sₙ/√n normalization.
  • Practical Defense Implications: Because raw scores Sₙ diverge in spread as n grows, defenders cannot rely on single-system outcomes. Normalizing by √n provides a stable metric to evaluate system security posture independent of deployment scale.
